## Project Overview
Analysis of ~1M anonymized Aadhaar enrolment records to uncover societal trends (migration, child welfare), anomalies, and 2026 forecasts using Python (Pandas, Prophet, Isolation Forest) and Power BI.

## Key Files
- `analysis_notebook.ipynb`: Full Python code (EDA, anomalies, forecasting)
- `forecast.csv` / `anomalies.csv`: Exported results
- `dashboard.pbix`: Power BI interactive dashboard (or screenshots in /images/)

## How to Run
1. Open `analysis_notebook.ipynb` in Jupyter/Colab
2. Install dependencies: `!pip install pandas seaborn prophet scikit-learn`
3. Run all cells
